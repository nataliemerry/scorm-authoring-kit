# Image production and provenance

Reuse the supplied raster assets for a visually identical baseline. A new topic needs meaningful topic-specific art, not merely recolored rectangles or emoji. Read the actual image-generation tool/skill available in your agent environment before invoking it; tool names and supported models differ.

## Asset set per course

- One 16:9 immersive scene background: professional Indonesian workplace, quiet darker left third, recognizable objects mainly center/right, no UI rendered in the image.
- Two isolated topic objects with real alpha transparency, three-quarter view, complete silhouette and generous margin. These recur in theory and situations and may label drag targets.
- One shared completion illustration, reusable across courses. It is not evidence that an LMS reward was awarded.

Use the existing six course images and shared reward as style references. Backgrounds and object cutouts must look like parts of the same world. Adult, premium tactile editorial 3D, matte materials, natural light, petrol teal/sage/ivory, restrained amber, coherent perspective. No childish mascot, neon cyber cliché, arbitrary gradient blob, screenshot, web mockup, infographic, generated paragraphs, logos or watermarks. Keep all readable text as HTML.

## Prompt templates

Scene:

> Create an immersive full-screen background for a professional Indonesian workplace learning course about {topic}. Show {concrete environment and two meaningful objects related to the decision}. Premium tactile editorial 3D, sophisticated matte materials, natural daylight, rich spatial depth, petrol teal, sage, muted amber and ivory. Landscape 16:9. Main identifiable objects in center-right 65%; left third darker and quiet for live text overlays. Render an actual environment, not an interface, slide, card grid or infographic. No words, letters, numbers, logos or watermark. Adult professional aesthetic. Match the attached baseline reference's lighting and materials.

Object:

> Create an isolated {specific object} for the same professional learning course. Three-quarter view, complete coherent silhouette, centered with generous transparent margin. Premium tactile editorial 3D, matte petrol teal, sage and ivory, restrained amber detail, refined studio light and subtle contact shadow. Match the attached reference's perspective and material. Real transparent background. No words, brand, watermark, frame or opaque backdrop.

Use explicit `transparent_background=true` when supported for cutouts; a prompt alone may not produce alpha. Do not put transparency on full-scene backgrounds. Inspect before editing a local reference. Request one distinct asset per generation call unless the available tool explicitly supports independent prompts safely.

## Agent and model handling

Codex: prefer its native GPT Images/image generation tool when available. Copy the returned project-bound files into the project; do not leave references pointing to the agent's cache. Other agents: use an available image tool/API approved by the user, or reuse the bundled assets. If generating is unavailable, state that limitation and provide ready prompts; do not claim an SVG substitute or stock image was generated by GPT Images.

Do not silently invoke a paid API, change provider/model, install an image tool, or expose credentials. If an external API path is explicitly authorized, read current provider documentation and use the supported workflow. Record the actual model when exposed; otherwise record “model identifier not exposed by tool”. Do not fabricate a model name from the marketing label. Never embed API credentials or absolute cache paths in course output.

## Inspection and preparation

Inspect every asset at intended scale and on both ivory and dark scene backgrounds. Check subject relevance, odd geometry, fake text, clipping, unused blank canvas, visual contrast and alpha edges. If a cutout contains an opaque background, fix through the image tool. Avoid unrequested pixel manipulation as a substitute for image editing.

Keep selected master PNG files. Create local distribution WebP derivatives while preserving alpha (format conversion is allowed). Do not upscale a tiny source to meet a nominal resolution. Use approximately 1536px wide or larger for a desktop scene and approximately 768–1024px source dimensions for object art when the generator supports it; inspect actual quality rather than relying on size alone. Optimize bytes without obvious compression artifacts.

Reference images explicitly in eXe source HTML using `{{context_path}}/scenes/...`, even if JS later displays them. Store actual resource files in `content/resources/`. JSON-only image references can be missed by the importer. Bundle files in the SCORM manifest. Use neutral empty alt for purely decorative repeated objects, meaningful alt for instructional images.

## Prompt log

For each accepted image, record `file`, `role`, `prompt`, `tool`, actual model identifier if exposed, generation date, reference image files, transparency requested and inspected, output dimensions, selected master and derivative paths. Record the actual action: copied baseline ≠ newly generated. Do not invent provenance for bundled historical assets; original prompts are in `exelearning/pilot/asset_prompts.json` and `docs/asset_prompts.json`.

## Institutional logo

The BPS CorpU logo is an official extracted asset, **not AI-generated**. Use `assets/branding/bps-corpu-transparent.png` and the source record beside it. Preserve the original PNG alpha, colors, words and aspect ratio. Include it explicitly as `data-brand-logo` in source Text content and as `content/resources/branding/bps-corpu-transparent.png` in exports. Topic-art regeneration must not replace the institutional logo. Its use adds one PNG to the four generated WebP assets per course.
