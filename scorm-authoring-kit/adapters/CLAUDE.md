# SCORM LCM — konteks Claude Code

Untuk pekerjaan SCORM LCM, baca `scorm-exe-scenes/SKILL.md` pada path paket yang benar. Ikuti referensi terkait dan pakai starter yang disertakan sebagai acuan implementasi, bukan menggambar ulang desain dari deskripsi.

Alur: sampul → 3 materi bersumber → cek pemahaman → 2 situasi → Find the words → Drag the Words → Sort the Paragraphs → kasus DnD wajib → 2 soal native → pembahasan → hasil. Tiga aktivitas tambahan boleh dilewati melalui tombol lanjutnya; kasus tetap wajib sebelum kuis. Nilai hanya berasal dari dua soal native.

Find the Words menempatkan istilah dari kiri ke kanan atau atas ke bawah. Tampilkan petunjuk makna, jumlah huruf, dan tombol Tunjukkan huruf awal per soal. Istilah tampil setelah ditemukan atau saat peserta meminta jawaban. Ulangi menyembunyikan istilah dan menghapus bantuan. Drag the Words memiliki bank kata. Sort the Paragraphs memiliki pegangan, tombol Naik/Turun serta keyboard dengan Esc untuk membatalkan. Pertahankan input mouse/sentuh/keyboard, pemindahan yang dapat diurungkan, serta pemisahan bantuan dari penyelesaian mandiri.

Pertahankan logo resmi transparan di kiri atas, nama institusi/kursus, fullscreen saja di sisi header lainnya, font lokal, isi/tombol ≥16px dan keterangan ≥14px. Narasi Indonesia semi-formal natural profesional; rujukan primer per paragraf, contoh berlabel simulasi dan provenance gambar yang sebenarnya.

Adaptasi cabang kode khusus topik sesuai implementation-map; brief bukan input build otomatis. Ekspor aktual melalui eXeLearning Online, kemudian uji ZIP asli. Jika tool browser/gambar tidak tersedia, laporkan langkah yang belum dapat dilakukan. Jangan menimpa instruksi proyek lain atau mengklaim ekspor/LMS/aset yang tidak dilakukan.

Pisahkan jalur kata dengan huruf pengisi. Buat setidaknya satu perpotongan tegak lurus pada satu huruf yang sama di tengah kedua kata. Hindari jalur yang bersentuhan di ujung atau menempel sejajar.
