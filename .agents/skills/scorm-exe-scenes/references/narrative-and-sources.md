# Natural Indonesian and verified material

Default register is already decided: semi-formal, natural, professional Indonesian, using “Anda”. Do not repeatedly ask for tone. Another language or audience may be set explicitly in the brief.

## Writing

Explain the concept directly, use familiar workplace nouns and active verbs, then show how it applies in a separate example. Vary sentence length when it helps understanding. Cut introductory ceremony, repeated conclusions, forced contrasts and motivational filler. Keep terminology consistent and explain an unfamiliar term when it first matters.

Avoid generic patterns such as “Di era digital yang terus berkembang…”, “Mari kita jelajahi…”, “bukan hanya X, tetapi juga Y”, “langkah kecil menuju perubahan besar”, and repeated “Penting untuk dipahami…”. Do not replace these with an equally rigid list of approved phrases.

Useful baseline examples:

- Theory: “Input adalah sumber daya yang digunakan. Keluaran (output) adalah produk atau layanan yang dihasilkan kegiatan.” A reference is attached to this paragraph.
- Case: “Laporan menunjukkan serapan anggaran 90%, tetapi keluaran pekerjaan baru 55%.” These are fictional case values.
- Instruction: “Pilih satu jawaban, lalu tekan Periksa jawaban.”
- Feedback: “Penyebab keterlambatan belum diketahui. Periksa hambatannya dahulu agar kebutuhan belanja berikutnya dapat dinilai.”

Do not make every explanation a slogan, rhetorical question, perfect three-part list or tidy moral. Feedback names the consequence and the reason. It does not praise the participant's character. Preserve technical qualifications, numeric constraints and answer keys when editing prose. Audit first and edit only weak spans; keep original/reference versions. If a humanize skill exists, it may help, but this file is sufficient without it. Do not promise detector scores or human authorship.

## Research and verification

1. Identify the exact claims each theory paragraph will make, then find primary publications or official institutional guidance. A reputable institution's homepage alone does not support a specific claim.
2. Open and read the relevant section. Check publisher, title, publication/update date, applicability and current version. For rules/regulations, verify amendment/repeal status and jurisdiction. A search snippet or HTTP 200 alone is insufficient.
3. Record the direct URL, section/entry, PDF page when applicable, DOI if present, date actually checked, and a short statement of what was verified. Distinguish printed page numbering from physical PDF page numbering.
4. Paraphrase in Indonesian without changing scope. Preserve limitations: e.g. “MFA helps” does not mean every MFA method is phishing-resistant. Do not derive a legal requirement from a general OECD recommendation.
5. Map every paragraph to one or more source numbers. Render `[1]`, `[2]` links near the supported text plus a visible “Sumber materi” list on that same page. Include publisher, title, year, section/page and verification date. Keep external links in a new tab with `noopener noreferrer`.
6. Label examples “Contoh simulasi” and explain that cases/data were composed for practice. Reference the principle, but do not attribute invented dialogue or costs to the publisher.

Source data fields are demonstrated in `data/pilot_lessons.sourced.json` and `data/pilot_references.json` in the unpacked project. `paragraph_sources` contains one list of 1-based source indices for each body paragraph separated by `\n\n`. Every index must resolve to `references`. The current baseline verified date is 2026-11-13; never copy that date to new research without checking.

If a source is unavailable, use another verified source for the same claim or mark the claim unresolved in the editorial draft. Do not invent a citation or mark it verified. A source list included only in the project README does not satisfy the course UI requirement.

The existing five references support C01/C12 only. Reuse them only for supported claims. New topics need their own research. Keep runtime offline; references can open the publisher site when internet is available.
